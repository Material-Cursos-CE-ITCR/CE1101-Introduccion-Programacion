### Palindromo de un número
Dado un número entero n, determina si es un palíndromo.

Un número se considera palíndromo si se lee igual de izquierda a derecha que de derecha a izquierda. Por ejemplo, 12121 y 555 son palíndromos, mientras que 123 no lo es.

1. Ejemplo utilizando operaciones de módulo y división entera: [Palindromo con módulo y división entera](https://github.com/Material-Cursos-CE-ITCR/CE1101-Introduccion-Programacion/blob/main/Ejemplos/palindromo.py)
2. Ejemplo utilizando operaciones de listas e índices:[Palindromo convirtiendo en lista - menos eficiente](https://github.com/Material-Cursos-CE-ITCR/CE1101-Introduccion-Programacion/blob/main/Ejemplos/palindromo_listas.py)
